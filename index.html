PROJECT NOTES NORTHSTAR ACADEMY

About this project

A lightweight tool for making student progress easier to understand.

THE PURPOSE

Student success, in focus.

This dashboard turns a small sample of student results into a useful overview for educators. It brings achievement and attendance together so teams can spot patterns, celebrate progress, and find students who may benefit from support.

—sample student records loaded locally
BUILT WITH

Simple by design

  • Semantic HTML5 sections and controls
  • Responsive CSS with system fonts
  • Vanilla JavaScript and browser fetch()
  • Local static JSON dataset and inline SVG charts
ACCESSIBILITY

Usable by more people

  • Keyboard-operable navigation and buttons
  • Visible focus styles and clear labels
  • Live result counts, status text, and chart descriptions
  • Accessible modal details and reduced-motion support
PERFORMANCE & QUALITY

Lean and reviewed

  • One small JSON request; filtering runs in memory
  • Document fragments for efficient table updates
  • No frameworks, fonts, or third-party dependencies
  • Verified locally for navigation, filters, sorting, details, and responsive layout
